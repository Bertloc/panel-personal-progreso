# Panel Personal de Progreso

App personal en Angular para organizar finanzas, deuda, ahorro, hábitos, progreso anual y proyectos personales.

## Estado actual

Primera versión visual con:

- Dashboard principal
- Pantalla de dinero
- Hábitos
- Progreso anual
- Proyectos
- Modo oscuro
- Navegación inferior
- Botón flotante
- Datos mock iniciales

## Tecnologías

- Angular
- Tailwind CSS
- TypeScript
